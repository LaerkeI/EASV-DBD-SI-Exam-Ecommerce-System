# EASV-DBD-SI-Ecommerce-System

This project contains an e-commerce system implemented using a microservice-based architecture. It uses RabbitMQ for messaging between services, MSSQL for order and inventory data, MongoDB for the product catalog, Redis for catalog caching, and Jenkins for CI/CD.

Check out the demos for this system in the "demos" folder. 

In the "docs" folder are notes concerning common errors, RabbitMQ messaging, how to setup the Jenkins pipeline, how to setup a reverse proxy with ngrok, and how to setup a Kubernetes dashboard.
